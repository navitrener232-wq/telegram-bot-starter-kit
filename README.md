# 🤖 Telegram Bot Starter Kit

**Build Your Telegram Bot in 5 Minutes**

Complete production-ready template with admin panel, database, and payment integration.

## 🚀 Quick Start:

```bash
git clone https://github.com/navitrener232-wq/telegram-bot-starter-kit.git
cd telegram-bot-starter-kit
pip install -r requirements.txt
cp .env.example .env
# Add your bot token
python bot.py
```
